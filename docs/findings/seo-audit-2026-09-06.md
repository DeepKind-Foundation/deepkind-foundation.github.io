## Critical Findings (FIXED ✅)

### 1. AI Crawler Access — robots.txt
**Issue:** No explicit allow directives for AI search crawlers (Google-Extended, OAI-SearchBot, Claude-SearchBot, PerplexityBot).  
**Impact:** AI answer engines (ChatGPT, Perplexity, Gemini, Claude) may not cite the foundation despite being indexed.  
**Fix:** Added explicit `User-agent` + `Allow: /` groups for:
- Google-Extended (AI Overviews)
- OAI-SearchBot, ChatGPT-User (ChatGPT search)
- PerplexityBot, Perplexity-User (Perplexity)
- Claude-SearchBot, Claude-User (Claude search)
- GPTBot, ClaudeBot, CCBot (training, allowed by policy)

**File:** `public/robots.txt`  
**Status:** ✅ Deployed

**Verify:**
```bash
curl https://deepkind.org/robots.txt | grep "Google-Extended"
```

### 2. NGO Entity Metadata — JSON-LD
**Issue:** NGO schema missing tax/registry IDs, founding date, donation action, and corroboration links (Wikidata, spis.ngo.pl, KRS registry).  
**Impact:** Google Knowledge Graph cannot establish entity identity; AI models cannot verify nonprofit legitimacy.  
**Fixes:**
- ✅ Added `taxID: "5214132486"` (NIP)
- ✅ Added `identifier: { propertyID: "KRS", value: "0001193215" }`
- ✅ Added `potentialAction: { @type: "DonateAction", target: "https://deepkind.org/wesprzyj" }`
- ⏳ Ready for `foundingDate` (awaiting user date)
- ⏳ Ready to expand `sameAs` with Wikidata + registry URLs

**File:** `src/components/layout/BaseLayout.astro` (lines 64–82)  
**Config:** `src/data/content.json` → `footer.org` (already has `nip`, `krs`, and new `foundingDate` field)  
**Status:** ✅ Deployed (partial); awaiting user data for completion

**Verify:**
```bash
curl -s https://deepkind.org | grep -o '"taxID":"[^"]*"'
curl -s https://deepkind.org | grep -o '"KRS"'
```

### 3. Crawlable Bilingual Site — /en/ Routes
**Issue:** No server-rendered English site; only client-side i18n toggle (invisible to crawlers). No hreflang tags. Blocks international partner reach and AI citation in English queries.  
**Impact:** Zero crawlable English URLs; hreflang required for dual-language SEO; AI models see only Polish content.  
**Fixes:**
- ✅ Built real `/en/` Astro routes mirroring PL pages
- ✅ Added hreflang triplets to every page (pl, en, x-default → PL canonical)
- ✅ Updated BaseLayout to accept `lang` prop; sets `<html lang>` + `og:locale` dynamically
- ✅ Refactored 7 section components to accept optional `content` prop
- ✅ `/en/index.astro` passes EN content to all sections
- ✅ Sitemap auto-includes `/en/` routes
- ⏳ Blog translation scoped for Phase 2 (needs translated posts + lang field)

**Files:**
- `src/pages/en/index.astro` (new; mirrors homepage)
- `src/components/layout/BaseLayout.astro` (lang prop, hreflang tags)
- `src/components/sections/*.astro` (7 components refactored to accept content)
- `src/i18n/getContent.ts` (new; language selection helper)
- `src/data/content.en.json` (already exists; restructured with title field for Hero)

**Status:** ✅ Deployed; blog EN deferred to Phase 2

**Verify:**
```bash
curl -s https://deepkind.org/en/ | grep -o 'hreflang="[^"]*"'
curl -s https://deepkind.org/sitemap-0.xml | grep "en/"
```

### 4. Blog Author Attribution — Person Schema
**Issue:** All blog posts attributed to Organization (Foundation), not author. No visible byline.  
**Impact:** AI citation models cannot attribute articles to real experts; E-E-A-T signals diffuse across brand instead of concentrating in named author.  
**Fixes:**
- ✅ Created `src/data/authors.json` with author metadata (name, title, URL, sameAs, photo)
- ✅ Updated `src/pages/blog/[slug].astro` to lookup author in JSON and emit Person schema
- ✅ Added visible byline: author name + date (e.g., "Joanna Lange · 6 wrz 2026")
- ✅ Fall back to Organization schema if author field is empty

**Files:**
- `src/data/authors.json` (new; keyed by author name)
- `src/content.config.ts` (blog schema unchanged; `author` remains a lookup key)
- `src/pages/blog/[slug].astro` (author schema logic + byline rendering)

**Status:** ✅ Deployed

**Verify:**
```bash
curl -s https://deepkind.org/blog/czy-ai-moze-byc-zyczliwa/ | grep -o '"author":{[^}]*"@type":"Person"[^}]*}'
```

## Medium-Priority Findings (FIXED ✅)

### 6. Sitemap Freshness Signals — lastmod
**Issue:** Sitemap lacked `<lastmod>` tags for blog posts; no freshness signal to Google.  
**Fix:** Added `serialize()` callback to `@astrojs/sitemap` config to set `lastmod` for `/blog/` URLs.

**File:** `astro.config.mjs`  
**Status:** ✅ Deployed

**Verify:**
```bash
curl -s https://deepkind.org/sitemap-0.xml | grep -A1 "/blog/" | head -10
```

---

### 7. Per-Post Social Preview Images
**Issue:** All pages use generic og:image; blog posts should have unique per-post images for higher social/AI shareability.  
**Fix:** Added optional `ogImage` field to blog schema; falls back to generic image when absent.

**Files:**
- `src/content.config.ts` (ogImage schema field)
- `src/components/layout/BaseLayout.astro` (dynamic og:image selection)
- `src/pages/blog/[slug].astro` (pass ogImage to layout)

**Status:** ✅ Infrastructure deployed; images added opportunistically as they become available
